# 角色提示词经验内化 Plan

类型：协作规则/提示词文档维护。用户已授权将本轮项目感悟与文档经验内化到 code agent 体系，重点为各角色提示词及上下文。

目标：在现有 base、specialists 和七角色正文中形成可执行指导：完整目标与流程、独立判断、简单且足够明确的设计、原生能力优先、文档单一归属/分层、最小上下文、真实证据及结算后可接续。保持当前产品行为、角色权限、工具协议与交付责任。

范围：九份 prompts、G4/G5 上下文/模型检查、I4 实际模型场景、导航/当前验证说明。只提炼已讨论经验，不修改外部 skill，不新增规则文件、对象、审批类型或程序门禁。

上下文：AGENTS.md、docs/INDEX.md、当前技术入口、角色工具契约、提示词、产品需求管理/任务交付/项目知识及 skill 设计/独立角色/结算流程。排除旧代码、docs/old 和旧方案作为规范；讨论中的经验用于指导行为，不代替正式事实。

步骤：根 Agent 单独编辑 → 两个干净上下文只读审阅（角色/上下文一致性、独立开发可理解性） → 修正具体发现 → 链接/契约静态检查与 diff 核对 → 记录审阅/验证/结算 → 仅提交本次文件。

完成依据：经验进入真正注入的正文；角色职责清楚、无重复 Schema/业务规则或新增流程义务；独立读者能理解做什么和如何按索引工作。文档检查不证明实际模型已遵守，运行行为仍 NOT_RUN。
