## 入稿步骤

1. 浏览器打开`index.html`通读。后台标题可用“AI 说‘完成了’，然后呢？从会写代码到可交付的 Agent”；正文顶部已有题目和副题，是否保留以后台预览决定。
2. 打开`wechat-copy.html`复制浏览器渲染后的正文，或通过自己的HTML编辑工具导入；不要把源码作为文字粘贴。
3. 在公众号后台上传表内四张PNG，在对应位置插入或替换。本地相对路径和data URI均不是已上传素材地址；使用HTML编辑工具时，先上传素材再替换`img src`。
4. 发手机微信预览，检查段落、链接、图中文字、比例与图注。后台可能改写样式或处理图片，应以实际预览为准。
5. 账号所有者另选封面、核对裁切并发布。本包专注正文插图。

未执行后台粘贴、素材上传、草稿创建、手机微信预览、封面裁切或群发；不承诺后台保留全部内联样式。Chrome截图仅证明本地已检查视口的呈现。
