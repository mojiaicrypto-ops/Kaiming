## 文件与用途

- `index.html`：完整离线阅读版。四张 PNG 以 data URI 嵌入，全部 CSS 写在元素 `style` 中，无 JavaScript、远程样式、字体或图片请求；单独保存这一个文件即可阅读。
- `wechat-copy.html`：公众号复制素材。它是可在浏览器打开的完整 HTML，正文与离线版相同，全部样式内联，图片使用 `assets/*.png` 相对路径。用于复制浏览器渲染后的正文，或交给支持 HTML 的编辑工具；不是可直接上传的公众号草稿/API 请求。
- `assets/`：四张原创工程图的 SVG 可编辑源文件与 2 倍高清 PNG。文章使用 PNG，不依赖微信渲染 SVG。
- `agent-delivery-system-wechat-v2.zip`：上述两个 HTML、README 与 assets 的分发包，不包含 ZIP 自身。

## 入稿步骤

1. 用浏览器打开 `index.html`，通读正文和四张图。后台标题可用“AI 说‘完成了’，然后呢？从会写代码到可交付的 Agent”；正文顶部保留了题目与副题，是否重复展示以实际后台预览决定。
2. 如从浏览器复制，打开同目录 `wechat-copy.html`，复制渲染后的正文，不要把 HTML 源码作为文字粘贴。使用自己的公众号编辑流程导入，核对后台保留了哪些样式。
3. 在公众号后台上传 `assets` 内四张 PNG，在对应位置插入或替换图片。本地相对路径及 data URI 都不是已上传素材地址。如使用 HTML 编辑工具，先上传，再替换相应的 `img src`。
4. 向手机发送微信预览，检查标题、段落、链接、图中文字、图注以及深色工程图在手机上的显示。后台可能重写样式或处理图片，必须以实际预览为准。
5. 封面由账号所有者另行选择并核对裁切。本包专注正文工程解释图，不提供口号封面。确认后由账号所有者发布。

本次未执行后台粘贴、素材上传、草稿创建、手机微信预览、封面裁切或群发发布；不承诺后台对全部内联样式的保留。Chrome 静态检查只说明本地文件在已检查视口的呈现。
