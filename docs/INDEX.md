- [数据契约](architecture/data.md)：字段、枚举、产物、约束与迁移。

## 加载配方

主管先读产品总览和当前Work，再选择相关功能；开发读工作包、授权Plan和对应架构/AC；Review读相同正式依据及冻结Diff，使用独立上下文；Test读有效Review、验收和环境；Settlement读实际变化和知识入口。
