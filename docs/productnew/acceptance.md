# 产品验收

## 如何使用

本页检验用户能否完成实际工作，产品定义见 [总览](README.md)，操作过程见 [用户流程](journeys.md)。每项记录实际用户输入、可见结果、成果/资料和必要证据；文档检查通过不等于产品验收通过。

在同一 AgentDev 实例的一个全局 Server 中准备三个独立项目：A 有代码和已有文档，B 为第二个项目，N 没有 Git。有可用模型，也测试模型不可用。每项场景独立准备，不能借用上一场景偶然留下的状态。接续场景要实际关闭、断线或重启，不能只改显示标签。

## 整体交付检查

必须实际走通 [总览案例](README.md) 和 J-01～J-10，覆盖设计转化、标准、轻量、文档工作，以及断线、暂停和接续。

用户最后应能回答：做了什么、检查了什么、没做到什么、成果在哪里、项目知识是否更新、下一次如何继续。任何一项只能靠作者口头解释，不能算完整可用。

结果分别记录通过、失败、未执行、环境阻断或明确允许的风险处置。测试夹具只能证明相应可靠性行为；主管能否合理组织需求和知识，需审阅实际产物；完整用户流程需要实际可用模型和浏览器操作。未实现或未执行不能记通过。
