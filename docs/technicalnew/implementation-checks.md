# 实施入口与设计验证

本页是实施 Agent 的工作导航与验证契约。当前所有 SDK/模型/崩溃/浏览器场景为 NOT_RUN；文档审阅通过仅证明文档可用于下一步。

## I1 Pi 接入必须先通过的试验

固定 @earendil-works/pi-coding-agent / pi-ai v1.0.0。试验代码在独立最小目录完成，不先写业务框架。每项保存命令、配置、原生 JSONL、DB/工具记录和观察；不得用假回调代替真实 SDK 行为。

| 编号 | 操作 | 必须证明；失败后的设计路径 |
|---|---|---|
| PI-01 | 普通/自定义输入、首次文件创建、模板、压缩/分支、扩展拦截；各边界重启 | inputId 精确映射 marker/root；不重复追加；关联不明采用 interrupted/handoff，不能改原生消息字段 |
| PI-02 | 原生重试、工具失败、message_end/agent_end/agent_settled；注入 JSONL 写失败 | 正确区分停稳/业务成功/磁盘边界；不靠事件或内存 leaf 宣布 completed |
| PI-03 | 工具已生效且 DB 有回执，Pi 缺 ToolResult；公开 appendMessage 配对、分支与重复补写 | 只补原工具结果，不重做效果，重建后的继续行为正确；不通过则默认新 contextEpoch 交接 |
| PI-04 | 连续流式输出时准备快照/订阅、messageKey 转原生条目、压缩、代次替换 | 边界内快照 + 边界后增量不丢不重；无法关联明确重同步 |
| PI-05 | 关键意图/回执写失败，批量工具调用、ctx.abort、外层等 idle | 不再启动后续效果，不能只 throw；已启动效果如实待核实，Server 重启保持阻断 |
| PI-06 | abort 本地 bash、超时、子进程/脱离管理影响；停止与结束竞态 | 确认停止才停态；无法确认的后代进程保留未知，不宣传自动回滚/隔离 |
| PI-07 | 多 cwd/多模型并行，恢复原文件、模型不可用、角色工具/规则变化 | 不串项目，不改全局 cwd/env，不默认回退，冷恢复重建整个运行契约 |
| PI-08 | SDK uiContext confirm/select/input；父委派等待中由宿主转发子请求、直接答复；各保存边界重启 | 无并发 prompt/循环等待；只在主管展示；原请求原批次续接；响应丢失复用、拒绝不执行，原 Promise 丢失按 S7 核对/交接 |
| PI-09 | 容量=1，主管等待子工作/用户，多个子 Session 排队；各 UI/委派/容量等待 abort、stale、超时后接续 | 等待释放执行容量、保留逻辑 Session 所有权，子工作可运行；每个等待可取消并退订，abort 实际回到 idle；停止父等待不误取消子工作，不重建成员 |

未通过 PI-01/02/05/07 前不实施需要可靠 Task 的模型执行链路；可以先实现纯存储/查询。PI-03 的回执修补是条件能力，handoff 路径可作为首版交付。PI-04 必须在交付实时 UI 前通过；PI-08/09 必须在交付同步协作/授权前通过。

## I4 提示词与真实业务检查

检查七个角色实际收到 base/适用共同规则/完整角色正文及其 Task、Plan、依据入口；链接不能代替加载。检查分析 Task 保存报告后停稳收口、所有专业委派都绑定 Task、同一需求规则跨文档引用而非重定义、冲突能被发现。

至少用实际模型完成：自由讨论不保存、明确保存需求、模块内聚整理、标准开发、轻量 UI 文案、正式文档、多 Reviewer 与返工、主管总体 Plan 逐确认/默认授权、子内部计划不强制审批、授权拒绝与原批次继续、未知效果、结算缺项、新会话接续。查看实际工具调用、正式产物与证据，不只看回复像不像遵守规则。

数据库夹具证明可靠性条件；模型检查证明主管能合理组织；浏览器与实际环境证明可用。三类证据分别报告。适用产品验收以 productnew/acceptance 为准，不用技术自测代替。

## I5 改契约的处理

本目录唯一字段/语义定义：R1/R2 是公开输入与状态，S2 是持久记录，M2/M4/M5 是委派返回、UI 外层与原生交互，G2 是模型工具，requirements-format 是需求序列化，G4 是上下文装配，prompts 是角色执行指导。产品规则归属按 K-03。其他文档引用，不复制一套不同 Schema。

实施发现 SDK 不支持时，先记录失败试验、受影响契约与最小替代。若替代保持产品含义，可在技术设计审阅后落实；改变产品行为/验收/授权或风险接受，提供具体差异给用户决定。不能用局部代码默默改协议。
