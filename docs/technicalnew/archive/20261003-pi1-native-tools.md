## 已核对事实与采用

Pi 提供原生文件与 Shell 工具、指定 cwd、工具选择和扩展接入、取消与实际结束事件。Shell 有 timeout、AbortSignal 与进程树终止；文件与 Shell operations 可以替换。默认 write 仅完成文件写入，不提供项目需求的业务校验和跨存储事务。

tool_result 扩展异常会被捕获报告，不能把单纯监听器异常当作持久回执失败时的可靠阻断。关键执行记录需要明确成功核对及停止后续调度的路径，具体最小包装/扩展方式留待试验。

agent_end 不等于最终无续工作，agent_settled 才是后者；Task 完成仍依据独立验证与结算。任意 Shell 的未知副作用不自动重放。
