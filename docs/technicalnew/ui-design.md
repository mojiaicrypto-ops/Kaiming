# 浏览器前端设计契约

日期：2026-10-21。定义工作台浏览器界面的布局、视觉、组件与交互行为；产品能力由[产品总览第 6 节](../productnew/README.md#6-用户实际能看到和操作什么)约束，接入方式见 [A7](architecture.md#a7-前端层)。
本页是待实现契约：除"现状"一列标注的证据外，描述的是目标行为。

## U1 范围与现状

| 事实 | 证据 |
|---|---|
| 新外壳为 React 19 + Vite 7，构建于 `webapp/`，产物 `web-static/app` 托管在 `/app/` | `devagent/webapp/vite.config.ts`、`src/server/http.ts` |
| 旧外壳为无构建的原生 JS，服务 `/`，8 个视图已可用 | `devagent/web/` |
| 新外壳目前只有主管会话面（transcript、任务卡、交互卡、成员抽屉） | `devagent/webapp/src/components/` |
| 旧外壳的 CSS 由原型 mock 逐字节复制，不是最终设计 | `devagent/web/styles/OMISSIONS.md` |

目标：新外壳达到可交付水准并完成其余视图迁移，收口后 `/` 指向新外壳、旧外壳删除。

不包含：服务端业务语义、Agent 提示词、模型调度。

## U2 布局

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶栏 52：项目切换 · 会话切换 · 全局搜索(⌘K) · 连接状态                  │
├──────────────┬───────────────────────────────────┬───────────────────────┤
│ 侧栏 248     │ 主区                               │ 工作栏 320(可折叠)     │
│ 会话         │ 会话：transcript 滚动，宽度上限    │ 当前 Task / 计划步骤    │
│ 需求 任务    │ 820；输入框吸底                    │ 参与 Agent / 待决定     │
│ 文件 文档    │ 其他：page-header(唯一标题) + 内容 │ 证据与产物              │
│ 设置         │                                    │                        │
├──────────────┴───────────────────────────────────┴───────────────────────┤
│ 状态栏 26：连接 · 分支 · 运行摘要(单行，不重叠)                          │
└──────────────────────────────────────────────────────────────────────────┘
```

- 视图内部不得再渲染与 `page-header` 重复的标题或说明。
- 工作栏内容随路由上下文变化；无内容时整栏隐藏，主区获得宽度。
- 断点：`<1280px` 工作栏默认折叠；`<1024px` 侧栏改抽屉；`<768px` 单列。

## U3 令牌

唯一权威为前端令牌文件；组件内不得写死颜色、字号、间距。

| 类别 | 取值 |
|---|---|
| 背景 | 底色 / 面 / 抬升 / 内嵌四级中性深灰 |
| 边界 | 细分隔线与强分隔线两级 |
| 文本 | 主 / 次 / 弱三级 |
| 强调 | 单一强调色，仅用于主操作与当前项 |
| 语义 | 运行、待决定、完成、阻断、等待、空闲各一色，只表达状态 |
| 字阶 | 11 / 12 / 13 / 14 / 16 / 20 / 26；正文 14；字重 400/500/600 |
| 间距 | 4 的倍数（4/8/12/16/24/32/48） |
| 圆角 | 6 / 10 / 14 |
| 动效 | 状态 120ms、浮层 180ms，尊重减少动效设置 |
| 主题 | 深色为默认；浅色主题需同时提供全部令牌 |

## U4 组件

基础组件：按钮、图标按钮、输入、文本域、选择、复选、卡片、面板、列表行、徽标、状态点、状态标签、
头像、标签页、提示、对话框、抽屉、空态、错误态、骨架、通知、命令面板、Markdown、代码块、时间线、步骤列表。

规则：组件集中实现，样式随组件；其他位置不得新增一次性样式类；每个组件在组件画廊页列出全部状态。

## U5 会话面

| 元素 | 规则 |
|---|---|
| 消息分组 | 用户 / 主管 / 专业 Agent（带角色与 Session 入口）；组间 24，组内 8 |
| 流式 | 增量追加，不重渲染已完成消息；仅贴底时自动跟随 |
| 工具卡 | 默认单行（名称 + 一句摘要 + 耗时），展开看参数、输出与错误 |
| 计划与需求卡 | 内联，标题 + 摘要 + 进入详情 |
| 决定卡 | 置于输入框上方，问题为标题，选项为按钮，附依据；答复后变为已答复 |
| 输入框 | 吸底；发送键与换行键区分；发送中禁用并显示状态；排队与保留输入可见且可撤回 |
| 空态 | 价值主张 + 示例问题 + 主操作；不出现路径等实现细节 |
| 连接状态 | 区分未连接、重连中、已断开、服务不可达，各带一句原因与重试 |

## U6 状态语言

- 状态词面向用户：「正在执行（2 个 Agent）」「等你决定：…」「已阻断：…」「已完成」「已暂停」「空闲」。
- 状态由色点与文字共同表达，不能只靠颜色。
- 任何"完成/失败"可展开到来源：哪个 Agent、哪次运行、哪条报告。

## U7 可访问性与文案

- 焦点可见且顺序合理；图标按钮必须有可读名称；键盘可达全部操作（全局搜索、发送、关闭浮层）。
- 对比度不低于 4.5:1。
- 全部文案走界面文案资源，两种语言键一致；不得硬编码单一语言。

## U8 迁移矩阵

| 界面 | 旧外壳 | 新外壳现状 | 目标 |
|---|---|---|---|
| 会话 | 完整 | 有 | U5 |
| 需求 | 列表 + 详情 | 无 | 列表 + 详情 + 生命周期 |
| 任务 | 列表 + 详情 + 报告 | 仅会话内卡片 | 列表 + 详情 + 工作栏 |
| 文件 | 树 + 预览 | 无 | 树 + 预览 + 搜索 |
| 文档 | 索引 + 预览 | 无 | 索引 + 预览 |
| Agent | 角色配置 | 无 | 只读配置 + 会话入口 |
| 运行 | 控制台（Live/Events/Artifacts） | 无 | 任务详情内的运行抽屉 |
| 收件箱 | 恢复与待答 | 无 | 全局待办 |
| 设置 | 模型/语言/项目 | 无 | 设置页 |
| 全局搜索 | 有 | 无 | 命令面板 |

## U9 门禁

- 组件画廊覆盖全部组件状态。
- 三档宽度 × 深/浅主题截图快照。
- 现有浏览器场景迁移到新入口后全部通过。
- 两种语言的文案键一致。
