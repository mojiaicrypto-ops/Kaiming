# AgentDev 项目入口

先读 `.dev/INDEX.md`，再按当前任务读取相关产品、技术、代码/测试与项目补充规则。正式项目知识为事实依据，聊天仅作工作材料。

本项目使用 AgentDev 内置规则目录；主管在保存需求/交付/结算前读取适用规则，派发给专业角色的任务包含目标、范围和相应文档路径。不要默认全库加载。

## 项目参数

- 知识根：`.dev/`
- 需求目录：`.dev/requirements/`
- task 归档：`.dev/work/<taskId>/`
- planAuthorization：explicit_goal（可改 per_plan 逐计划确认）。用户明确实施目标授权范围内计划；产品/范围/验收/规则变化另外确认。
- 高风险：破坏性数据操作、生产服务操作、外部发布、凭证/权限变更须说明具体效果并明确确认。
- 工作区：同一工作区一个写执行，审核只读，测试使用临时环境。
- 复盘：每 5 个完成 task，以及漏检事故后提出具体改进。
- Git：提交本任务成果与证据；无 Git 可本机完成，必须标明未提交。
- 记录：默认保留；会话清理不能删有效引用、项目知识和 task 归档。

独立 Review/Test 和真实结果、结算不得由补充规则取消。具体路径约束/项目检查在 `.dev/rules/INDEX.md` 导航，未调查内容不冒充确定规则。
